📊 E-Commerce Analytics Dashboard (Google Sheets)
🚀 Project Overview

This project is an End-to-End E-Commerce Analytics Dashboard built using Google Sheets. It demonstrates how raw transactional data can be transformed into meaningful business insights using ETL processes, KPIs, pivot tables, and interactive dashboards.

The goal of this project is to analyze sales performance, customer behavior, and product trends to support data-driven decision-making.

🎯 Objectives
Transform raw e-commerce data into structured format
Perform ETL (Extract, Transform, Load) process
Build key business KPIs
Create interactive dashboards
Generate actionable business insights
📁 Dataset Structure

The project uses multiple datasets:

Customers Data
Orders Data
Products Data
Order Items Data
Fact Data (Final transformed dataset)
⚙️ ETL Process
🔹 Extract

Raw data imported from multiple CSV sheets:

Orders
Products

🔹 Transform
Data cleaning and validation
Handling missing values
Joining datasets using keys (Customer_ID, Order_ID, Product_ID)
Calculating Revenue = Quantity × Price
🔹 Load

Final structured dataset stored in:

Fact_Data sheet
